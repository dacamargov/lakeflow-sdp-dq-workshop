Workshop Lakeflow SDP + Data Quality

Construye un pipeline de datos completo en Databricks, de principio a fin, con Genie code

Un taller práctico donde cada participante levanta un pipeline productivo —ingesta, calidad, modelo dimensional y analítica— sin escribir el código a mano. Todo se arma con Genie code (Databricks Assistant) sobre Lakeflow Spark Declarative Pipelines (SDP), la evolución de DLT.

Para quién es

Ingenieros de datos, analytics engineers y arquitectos, además de perfiles de gobierno de datos, ciencia de datos, análisis de datos y BI que quieran ver, con las manos en el teclado, cómo Databricks reduce el esfuerzo de construir y mantener pipelines confiables.

No se requiere experiencia previa con SDP. Sí ayuda estar cómodo con SQL y conceptos básicos de datos.

Qué vas a construir

Partiendo de datos crudos de un retailer LATAM ficticio, cada quien arma en su propio espacio:

  • Ingesta bronze con Auto Loader y columnas de linaje.
  • Capa silver tipada y normalizada, con expectativas de calidad declarativas (emails válidos, montos no negativos, fechas coherentes, integridad referencial).
  • Capa gold con dimensiones limpias, un hecho de ventas y KPIs mensuales.
  • Analítica en lenguaje natural con un Genie Space y un dashboard AI/BI.

Lo que diferencia a SDP

CapacidadQué resuelve
CDC / SCD Tipo 2Historiza cambios de una dimensión sin escribir MERGE.
Cuarentena de datosAísla filas malas para auditar o reprocesar, sin perder nada.
ObservabilidadMide, desde el event log, cuántos registros pasan y fallan cada regla.
Ingesta incrementalProcesa solo los archivos nuevos, sin reprocesar lo viejo.
Evolución de esquemaAbsorbe columnas nuevas automáticamente, sin romperse.
Calidad por metadatosDefine decenas de reglas en una tabla, no en el código.

Agenda

  1. Contexto y setup — qué es Lakeflow SDP y por qué importa; preparar el entorno.
  2. Generar los datos — un notebook deja datos crudos (con "suciedad" intencional) en tu volumen.
  3. Medallion con Genie code — bronze → silver → gold, paso a paso, con prompts guiados.
  4. CDC / SCD Tipo 2 — historiza cambios de dimensiones sin escribir MERGE.
  5. Cuarentena de datos — aísla las filas malas para auditar o reprocesar.
  1. Observabilidad — métricas de calidad desde el event log del pipeline.
  2. Ingesta incremental — procesa solo los archivos nuevos del landing.
  3. Evolución de esquema — absorbe columnas nuevas automáticamente.
  4. Calidad por metadatos — reglas definidas en una tabla de configuración.
  5. Cierre analítico — Genie Space y dashboard AI/BI sobre la capa gold.

Duración estimada: media jornada (3–4 horas).

Qué te llevas

  • La experiencia de construir un pipeline real con muchísimo menos código que un enfoque tradicional.
  • Un repositorio con todos los notebooks y prompts para repetirlo con tus propios datos.
  • Criterio para decidir cuándo y cómo aplicar SDP en tus casos de uso.

Lo que necesitas

  • Un workspace Databricks con Unity Catalog y compute Serverless.
  • Un catálogo donde tengas permisos para crear esquema y volumen.
  • Genie code / Databricks Assistant habilitado.
Cada participante trabaja en su propio esquema aislado, así que varios pueden correr el taller en paralelo sobre el mismo catálogo sin pisarse. El admin del cliente tiene una guía dedicada con el SQL exacto de preparación.
